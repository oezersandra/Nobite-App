# Nobite App

A mobile-first Progressive Web App (PWA) to help users quit nail-biting through tracking, gamification, and emergency coping methods.

## Features
- **Dashboard**: Track your bite-free streak in days and hours.
- **Photo Diary**: Take or upload photos to visualize your progress over time.
- **Nail Pal**: A virtual companion (plant) that grows alongside your streak.
- **Emergency Methods**: Immediate, randomized coping strategies (like breathing exercises or mini-distractions) for when you feel the urge to bite.

## Development
This project is built with Vanilla JS, HTML, and CSS using Vite.
- To run locally: `npm run dev`
- To run locally and access from a mobile device on the same network: `npm run dev -- --host`
